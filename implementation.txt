# 4. GLOBAL INTERACTION SYSTEM

Create a global interaction layer.

It should include:

## Custom fluid cursor

Use the provided splash/fluid cursor reference as inspiration.

The cursor should:

* follow mouse movement smoothly
* have a glowing central point
* produce a fluid/particle-like trail
* stretch according to movement velocity
* dissipate naturally
* feel organic rather than like simple DOM particles
* react to acceleration
* have subtle color variation
* remain performant

Preferred implementation:

WebGL / shader-based effect.

Do not create hundreds of DOM elements for the trail.

The effect should be subtle enough that it does not interfere with readability.

### Cursor states

Normal:

Small fluid glow.

Fast movement:

Longer fluid trail.

Hovering interactive element:

Cursor expands slightly.

Hovering project:

Cursor changes behavior subtly.

Click:

Small fluid splash/ripple.

Text:

Optional slight cursor attraction.

Buttons:

Optional magnetic cursor effect.

### Mobile

Do NOT show the desktop cursor system on touch devices.

Provide an appropriate mobile experience instead.
